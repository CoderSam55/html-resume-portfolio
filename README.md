# HTML Resume Portfolio

A simple personal resume and portfolio webpage built using **HTML5**.

## 📌 About the Project

This project is a basic resume-style webpage created to practice and demonstrate the fundamentals of HTML5, including headings, paragraphs, lists, links, images, and page structure.

## ✨ Features

* Personal profile section
* Contact information
* Education details
* Work experience
* Skills section
* Achievements
* Projects section
* External links

## 🛠️ Technologies Used

* HTML5

## 📂 Project Structure

```text
html-resume-portfolio/
│
├── index.html
└── README.md
```

## 🚀 How to Run

1. Clone the repository.
2. Open `index.html` in any web browser.
